## Features
- ⭐ Favoriting: Easily view your most used assistants
- 👁️🚫 Hide: Instantly declutter the ui by hiding selected assistants
- ⏳ History: Quickly get back to the assistant you were just using
- ➕ Custom sites: Add other web apps in case the one you need isn't here
