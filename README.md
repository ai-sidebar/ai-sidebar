# AI Sidebar

Adds various AI assistants like ChatGPT, Claude, Gemini, Deepseek and others into your sidebar

## Features
- ⭐ Favoriting: Easily view your most used assistants
- 👁️🚫 Hide: Instantly declutter the ui by hiding selected assistants
- ⏳ History: Quickly get back to the assistant you were just using
- ➕ Custom sites: Add other web apps incase the one you need isn't here

## Important:
This extension does not embed of the chatbots websites into your sidebar, it simply opens the web app in your sidebar. This project was an independent project, none of the included companies were involved at all. Ai was involved in the development of this project
